## Barheru's Personal Repository of Space Station 14 Paperwork

Hello, my fine paperwork enjoyers. This is my repository for Space Station 14 paperwork. At this time, some formatting and details are specific to the Euphoria Server. You are free to use these forms for any purpose on any server, of course (server rules permitting)! But my formatting will focus on Euphoria. 

If you need general purpose SS14 paperwork and you don't want to edit the headers on mine, these two are excellent: [Moomoobeef's](https://github.com/Moomoobeef/ss14-forms-txt), [Tyto's](https://github.com/TheTyto/SS14-Advanced-Paperwork/tree/main)

The Formal Complaint Form is a derivation of Moomoobeef's, with the lore changes for Euphoria and harmonization with my own formatting. 

If you find a problem with formatting in a form, or I forgot to close a parenthese, or whatever, please let me know in issues and I will in fact fix it.

Forms in the "Lewd and Silly" folder should not be used on servers where ERP is against the rules. If you get banned for using one of those forms on WizDen, you did not understand the assignment!
